# PB v1 ("One Great Day") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build PB — a browser-based 3D paperboy-inspired delivery game (inspired by Data East's 1987 arcade game *Paperboy*) as one complete, polished delivery day: ride the street, throw papers on time, dodge cars, survive the rain, see the tally.

**Architecture:** Pure-TypeScript 60 Hz simulation with zero three.js imports (deterministic, seeded, unit-testable) that a three.js renderer reads every frame. WebAudio-generated audio (no binary assets). DOM overlay UI. All assets are programmatic low-poly models in a retro palette, behind a `ModelProvider`-style seam so real asset packs / glTF can be swapped in later.

**Tech Stack:** TypeScript, three.js, Vite, Vitest. Keyboard-only input (action-based, gamepad-ready). No React, no physics engine, no binary assets.

**Spec:** `docs/superpowers/specs/2026-09-16-paperboy3d-design.md`

## Global Constraints

- Product name is **PB** (never "Paperboy" as the product name; credits may reference Data East's *Paperboy* as inspiration).
- Browser target: must run via `vite preview` from a static `dist/` build; no server-side features.
- Simulation modules (`src/sim/`, `src/core/`) must have **zero** three.js imports.
- Fixed timestep: simulation steps at exactly `1/60 s`; rendering reads state after each frame's batch of steps.
- Determinism: identical seed + identical input sequence ⇒ identical simulation (same events, same final state).
- v1 input: keyboard only (WASD/arrows + Space + Enter). No mouse aiming, no gamepad (seam only).
- All audio procedurally generated via WebAudio (no audio files, no licensed audio).
- All 3D assets programmatic (three.js primitives + canvas textures). No binary model/texture files in git.
- No React, no state library, no physics engine.
- Every task ends with a git commit (message prefix `feat:` / `test:` / `chore:` / `fix:` / `docs:`).

`src/core/rng.ts`:
```ts
export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a |= 0;
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

`src/core/loop.ts`:
```ts
export class FixedLoop {
  private acc = 0;
  constructor(private readonly step: number, private readonly maxFrame: number) {}
  frame(dt: number, fn: (sdt: number) => void): void {
    this.acc += Math.min(dt, this.maxFrame);
    while (this.acc >= this.step - 1e-9) {
      fn(this.step);
      this.acc -= this.step;
    }
  }
}
```

`src/sim/rider.ts`:
```ts
import type { InputActions, Rider } from './types';
import { ROUTE_LEN, MAX_SPEED, ACCEL, BRAKE_DECEL, DRAG, THROW_MIN, THROW_MAX, CHARGE_TIME, AIM_RATE } from './types';

export function newRider(): Rider {
  return { x: 0, z: 3, heading: 1, speed: 0, stagger: 0, charging: false, charge: 0, aim: 0 };
}

export function stepRider(r: Rider, dt: number, input: InputActions): void {
  if (r.stagger > 0) {
    r.stagger = Math.max(0, r.stagger - dt);
    r.speed = 0;
    r.charging = false;
    r.charge = 0;
    r.aim += (0 - r.aim) * Math.min(1, dt * AIM_RATE);
    return;
  }
  if (input.throttle) r.speed = Math.min(MAX_SPEED, r.speed + ACCEL * dt);
  else if (input.brake) r.speed = Math.max(0, r.speed - BRAKE_DECEL * dt);
  else r.speed = Math.max(0, r.speed - DRAG * dt);

  r.x += input.steer * 4.5 * dt;
  r.x = Math.max(-3.2, Math.min(3.2, r.x));

  if (input.throwHeld) {
    r.charging = true;
    r.charge = Math.min(1, r.charge + dt / CHARGE_TIME);
    r.aim += (input.steer * 6 - r.aim) * Math.min(1, dt * AIM_RATE);
  } else {
    r.charging = false;
    r.charge = 0;
    r.aim += (0 - r.aim) * Math.min(1, dt * AIM_RATE * 2);
  }

  r.z += r.heading * r.speed * dt;
  if (r.z >= ROUTE_LEN - 3) { r.z = ROUTE_LEN - 3; r.heading = -1; }
  if (r.z <= 3) { r.z = 3; r.heading = 1; }
}

export function landingPoint(r: Rider): { x: number; z: number } {
  const d = THROW_MIN + (THROW_MAX - THROW_MIN) * r.charge;
  return { x: r.aim, z: r.z + r.heading * d };
}
```

### Task 5: sim/papers.ts

**Files:**
- Create: `src/sim/papers.ts`
- Test: `tests/papers.test.ts`

**Interfaces:**
- Consumes: `Paper`, `Rider`, `HouseSim`, `SimEvent`, `GRAV`, `PAPER_Y_LAND`, `YARD_IN`, `YARD_OUT` from types.
- Produces:

```ts
export interface PaperWorld {
  rider: Rider;
  houses: HouseSim[];
  wind: [number, number];
  lost: number;
  hits: number;
  addEvent(e: SimEvent): void;
  deliver(i: number, clockMin: number, raining: boolean): void; // houses.deliverHouse wrapper
}
export function launchPaper(w: PaperWorld, rider: Rider, id: number, charge: number): Paper
export function stepPapers(w: PaperWorld, papers: Paper[], dt: number, clockMin: number, raining: boolean): void
export function inPorch(h: HouseSim, x: number, z: number): boolean
```

Behavior (all deterministic, no Math.random):
- `launchPaper`: `T = 0.7 s` flight. Landing target = `landingPoint(rider)` (wind-free prediction — wind shifts the *actual* landing, which is the gameplay). Start at `(rider.x, 1.1, rider.z + rider.heading * 0.6)`. `vx = dx / T`, `vz = dz / T`, `vy = (PAPER_Y_LAND - 1.1 + 0.5 * GRAV * T * T) / T`. `target` = index of house whose porch contains the landing point, else `null`.
- Integration: `vy -= GRAV*dt; vx += wind[0]*dt; vz += wind[1]*dt;` then position update. Flutter is visual-only (render adds wobble); simulation has no flutter term.
- Landing when `p.y <= PAPER_Y_LAND && p.vy < 0`:
  - If on any porch → `w.deliver(i, clockMin, raining)`; `state='settled'; p.y = PAPER_Y_LAND; velocity zeroed`; event `paper_landed` kind `'porch'`, houseIndex `i`.
  - Else if in a yard band (`YARD_IN <= |x| <= YARD_OUT`) → bounce: `p.y = 0.05; p.vy = 1.8; p.vx *= 0.5; p.vz *= 0.5; p.bounces++`; on first bounce emit `paper_landed` kind `'yard'`. While bouncing, if `dist2d(paper, rider) < 1.4 && p.y < 1.6` → event `paper_hit_rider`, `w.hits++`, `state='gone'`. After `bounces > 2` → `state='gone'`, `w.lost++`.
  - Else (road or out of bounds) → event kind `'road'`, `state='gone'`, `w.lost++`.
- `state='gone'` papers stay in the array (render can drop them); caller prunes (GameSim caps the array, see Task 9).
- `inPorch`: `Math.abs(x - p.x) <= p.w / 2 && Math.abs(z - p.z) <= p.d / 2` where `p = h.spec.porch`.

### Task 12: audio engine

**Files:**
- Create: `src/audio/engine.ts`

**Interfaces:**
```ts
export type SfxName = 'whoosh' | 'thump' | 'bounce' | 'crash' | 'scatter' | 'ding' | 'jingle' | 'horn' | 'chime' | 'buzz';
export class AudioEngine {
  ensure(): void;                                  // lazily create/resume AudioContext (call on first user gesture)
  sfx(name: SfxName): void;
  startMusic(): void;
  setRainMusic(on: boolean): void;
  setAmbience(o: { speed: number; raining: boolean }): void;  // called per frame
  chainTick(riderSpeed: number): void;             // called per sim step while riding
  dispose(): void;
}
```

Implementation (all procedural — no audio files):
- `noiseBuffer(ctx, seconds, rand)`: loopable white-noise buffer helper.
- **SFX recipes** (short envelopes on oscillators/noise, through `master` gain 0.5):
  - `whoosh`: band-passed noise, sweep 400→2500 Hz over 0.25 s, gain 0.25 → 0.
  - `thump`: sine 90→50 Hz 0.18 s + low-passed noise burst, gain 0.4.
  - `bounce`: sine 220 Hz 0.06 s, gain 0.15 (quiet).
  - `crash`: loud noise burst (0.4 s, LP 800 Hz, gain 0.6) + descending square 200→60 Hz.
  - `scatter`: 6 short noise ticks over 0.3 s.
  - `ding`: sine 1318 Hz, 0.2 s decay, gain 0.2.
  - `jingle`: 4 square notes (784, 988, 1175, 1568 Hz), 0.12 s each, 0.05 s apart.
  - `horn`: two-tone square (440 + 330 Hz), 0.3 s, gain 0.12 (played rarely: on car spawn within 30 m of rider, max once per 20 s).
  - `chime`: sine 2093 Hz 0.3 s, very quiet (0.05) — on wind-chime sway peak.
  - `buzz`: sawtooth 110 Hz, 0.3 s (missed-house event).
- **Music**: interval scheduler (setInterval 280 ms, guarded by `ctx.state === 'running'`): 16-step loop, 8th notes @ 105 BPM — lead square through `BPF`: `[523,0,659,523,784,659,587,523,440,523,659,784,880,784,659,587]` (0 = rest); bass triangle every 4 steps: `[131,0,0,0,98,0,0,0,110,0,0,0,147,0,0,0]`; both through a low-pass: dry 2500 Hz / rain 700 Hz (`setRainMusic` crossfades filter + drops music gain to 0.6×); lead gain 0.08, bass 0.06.
- **Ambience** (persistent nodes, gains set by `setAmbience`): wind = LP(300 Hz) noise, gain `speed * 0.02`; rain = HP(1200 Hz) noise, gain `raining ? 0.18 : 0` (ramp 2 s); birds = when `!raining && speed < 1.5`, per-frame probability 0.004: chirp (sine 2500→3200 Hz, 0.15 s, gain 0.05).
- `chainTick`: if `speed > 0.5`, every 6th call: 15 ms noise tick through HP(2000), gain `0.04 + speed * 0.01`.
- Everything behind `ensure()`; no-audio environment (headless test runs) must not throw: every public method no-ops if `ctx` is null and no user gesture has occurred.
